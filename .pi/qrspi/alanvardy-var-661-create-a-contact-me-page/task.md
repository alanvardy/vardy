# VAR-661: Create a contact me page

Build a new `GET /contact` page on the vardy website that presents an HTML
form asking visitors for their name, email, and a message block. Public form
submissions must be protected against bots via an anti-robot challenge, and
valid submissions must be delivered to a personal inbox through an outbound
email sender (provider selection is part of this work). Submissions, and the
act of sending email, must be protected from spam/abuse.
