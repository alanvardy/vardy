to the axum web app, mirroring the existing SingleThread page exactly: reuse

  CheckStitch link to the shared nav in `templates/layout.html:25`

and `test.db` must exist — this worktree is fresh, so copy `.env` from the
canonical clone and run `cargo sqlx database create && cargo sqlx migrate run`
